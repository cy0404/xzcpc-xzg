# 2026-07-21 小程序端更新

## 调货还货/还钱模块
- **新页面**: `pages/transfer/return/index` — 还货/还钱操作页
- **入口**: 列表/详情页 completed 状态 + 调入方 → "还货"按钮; 调出门店 → "还货记录"按钮(审查模式)
- **操作模式**: 每项物料三个单选按钮 [仅还货][仅还钱][还货+还钱]
  - 仅还货:填数量;仅还钱:填金额(自动反推数量);还货+还钱:各自独立
- **全部还货/全部还钱**:标题行右侧胶囊按钮,仅填入不自动提交
- **归还记录**:内嵌在每个物料卡片中,展示时间+经手人+数量/金额
- **已还清标签**:`✓ 已还清` 绿色胶囊靠右居中
- **提交后**:刷新页面不跳走
- **仅还钱展示优化**:剩余行显示 `¥金额` 而非换算数量;已还汇总优先显示金额(非数量)

## 调货详情页优化
