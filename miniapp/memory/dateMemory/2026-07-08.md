# 2026-07-08 小程序端更新记录

## 物料盘点页（zone-entry）大改版

### 样式重构
- 页面设计系统对齐 CSS 变量（`#F7F8F6` 背景、`#2F8F57` 主色）
- 搜索栏：浅绿背景 `#F7FCF8` + 绿边框 `#D6EBDD`
- 新增橙色提示条："盘点提示"
- 物料列表：全部/待盘/已盘 三个筛选标签按钮，默认"全部"
- 底部按钮改为双按钮网格布局（结束盘点 + 语音搜索）
- 多单位抽屉保留原有逻辑不变

### 多单位抽屉增强
- 称重单位卡片：橙色背景 `#FFF8EE` + 橙色边框 `#E58A2D`，跨两列
- `hasWeightUnit` 判断：优先 `weightConversions`，回退 `conversionSnapshot` JSON
- `isWeightUnit` 按 `u === 'g'` 判断（配合 `inventory_units` 已加 g）
- 称重换算系数从 `weightConversions` 或 `conversionSnapshot` 取
- `=` 统一改为 `≈`
- 数值在单位下方独立一行

### 累加记录（append_records）
- **数据库**：`task_zone_material.append_records` TEXT 字段存 JSON 数组
- **后端**：`ItemSaveReq.appendRecords` 字段 + `MpZoneServiceImpl` 保存/返回
- **前端**：编辑抽屉累加模式下保存每次独立录入，不合并
- "总数"显示格式：`已盘 + 本次录入  81 + 2000 = 2081 个`
- 累加记录滚动列表，最多展示最近 2 条高度，自动滚到底部
- 关闭抽屉不自动保存，只有点"确认录入"才保存

### 允许录入 0
- `confirmDrawer` 移除了 `<= 0` 校验，只保留 `< 0`（负数拦截）
- 关闭抽屉时 `> 0` 才触发自动保存，0 不触发

### 数量异常校验
- 多单位 `confirmDrawer` 和单单位 `quickSave` 加了 `> 100000` 弹窗提示

### 抽屉滚动穿透修复
- 抽屉遮罩加 `@touchmove.stop.prevent` 阻止背景滚动

## 任务列表页（task/list）优化
- 点击任务卡片直接进物料盘点页（不调任务详情接口）
- zone-entry `onLoad` 支持无 zoneId 时自动取第一个分区

## 盘点汇总页（summary）优化
- 移除分区相关指标（分区总数/已完成/未完成）
- 物料列表去掉"X个分区"标签
- 所有物料展示多单位详情：`1杯 · 1件 · 1个`

## 语音搜索增强

### 智能解析
- `parseVoiceInput` 解析语音内容：提取物料名、数量、单位
- 动态单位列表从当前分区所有物料收集
- 中文数字 → 阿拉伯数字转换（一→1, 十→10, 百→100）
- 回退正则兜底：最后一段非空格作单位

### 自动操作
- 精准命中 1 个物料 → 自动开门回填数量和单位
- 模糊匹配多个 → 显示橙色提示："物料名100g，请点击下方物料，数量自动回填"
- 点击物料（待盘/已盘/搜索结果）→ `tryVoicePreFill` 回填
- 单位不匹配 → 丢弃解析值，开空抽屉
- 覆盖待盘 + 已盘两个列表

## 门店报损模块（loss-report）全新上线

### 新建页面

| 页面 | 说明 |
|------|------|
| `pages/loss-report/list/index` | 统计面板（今日/待确认/已补发）+ 日常/到货两个入口卡片 + 记录列表 + 底部新建弹窗 |
| `pages/loss-report/detail/index` | 状态标签 + 信息卡（2列网格）+ 处理结果 + 计算公式 + 图片备注 |

### 新增 API

| 文件 | 端点 |
|------|------|
| `api/loss-report.ts` | `getLossList`, `getLossDetail`, `createLoss`, `getContainers`, `searchMaterials`, `uploadLossImage` |
| `api/inventory.ts` | `scanBarcode`, `supplementBarcode` |

### 报损新建弹窗

- 两个独立抽屉（日常/到货），无 tab 切换
- **物料搜索**：输入关键词 → 300ms 防抖 → 搜全 `material` 表 → 展示名称+规格+分类+单位，选中后显示绿色标签
- **半成品去皮**：选中半成品物料时展示容器区域，容器为横向胶囊按钮（去皮/1号/2号/3号/4号），按 id 排序
- **容器详情卡片**：选中容器后下方展示左图右文卡片（容器图片/占位📦 + 名称 + 皮重描述）
- **净重公式**：绿色背景实时计算 `净重 XXg = 含容器重量 XXg - 容器名 XXg`
- **单位**：日常报损用 `base_unit`，到货验收用 `stock_unit`
- **必填校验**：物料必选、重量必填、容器必选、原因必填
- **图片上传**：最多 4 张，选图即显示本地预览（带上传中遮罩），异步上传完成后替换为服务器 URL
- **提交**：登记人取自 `handlerName`（员工姓名），日常报损状态 `closed` = "已记录"

### 报损详情页

- 顶部信息卡：状态标签 + 标题 + 图标 + 2列网格信息
- 处理结果卡片：日常显示"已记录，无需后续处理"，到货按状态区分
- 计算公式卡片：绿色背景净重公式
- 图片备注卡片：1张图方形展示，2张及以上竖排全宽展示

### 报损记录卡

- 类型标签（日常/到货验收颜色区分）+ 状态标签
- 半成品展示净重，成品展示数量
- 业务编码不展示（仅总部端可见）

### 工具页重构

- 分组布局：查看类工具（可跨门店，绿色标签）+ 执行类工具（需先选门店，橙色标签）
- 工具卡片 2x2 网格，6 种颜色渐变（绿/蓝/琥珀/橙/红/紫）
- 门店范围切换胶囊按钮（全部门店 / 当前门店）
- 执行类工具在全部门店模式下弹出选店弹窗
- 新增"门店报损"入口（红色卡片，执行类工具）

### 扫码盘点页

- `pages/inventory/scan/index`：进入自动调起 `uni.scanCode` → 后端识别 → 展示结果
- 扫码结果：✅ 识别成功 / ❌ 未识别 + 补充条码弹窗
- 根据物料状态：可录入 / 已录入（查看已盘） / 在其他分区（加入当前分区）

### 数据库

- `loss_report` 新增字段：`biz_code`、`reason`、`handler_name`（员工姓名）
- `container_config` 新增字段：`image`（容器图片 URL）
- 容器数据：去皮(id=1,0g), 1号(id=2,12g), 2号(id=3,25g), 3号(id=4,50g), 4号(id=5,80g)

### 后端

- `LossReportServiceImpl`：净重计算 + `determineRole` 权限（仅店长/老板）
- `BizCodeUtil.of("LOSS")` 生成业务编码
- 容器图片 URL 由后端拼接 `public-url` + 相对路径
- 容器排序按 `id` 升序
