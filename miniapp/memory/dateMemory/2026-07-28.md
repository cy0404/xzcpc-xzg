# 2026-07-28 物料盘点页搜索清除修复

## 物料盘点页搜索清除 Tab 不重置 bug

- **现象**: 搜索不存在的物料后点击搜索框 ✕ 清除，页面为空，没有回到「全部」Tab
- **原因**: `zone-entry/index.vue` 的 `watch` 中，搜索关键字变为空时（`!kw` 分支），只清理了 `extResults` 等状态，但没有将 `showPending` 和 `showDone` 重置为 `true`。此时两个 Tab 均处于 `false`（隐藏状态），页面显示为空
- **修复**: 在 `!kw` 分支中增加 `showPending.value = true; showDone.value = true;`
- **影响范围**: 仅 `zone-entry/index.vue` 第 832 行
- **覆盖场景**:
  - 点击 ✕ 清除搜索 → 回到「全部」Tab
  - 手动逐字删除搜索文字至空 → 回到「全部」Tab
  - 语音搜索取消/清空 → 同样生效
