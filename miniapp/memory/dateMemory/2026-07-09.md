# 2026-07-09 小程序端更新记录

## 调货管理模块上线

### 新增页面
- `pages/transfer/list/` — 调货列表页（概览卡片+方向标签+操作按钮+门店切换）
- `pages/transfer/detail/` — 调货详情页（物料清单+流程记录+底部操作）
- `pages/transfer/form/` — 发起调货（双门店自由选择+搜索+交接方式+物料+备注）
- `pages/transfer/item-select/` — 品项选购（搜索+底部抽屉录入+多单位+数字键盘）

### 品项选购（item-select）
- **底部抽屉录入**：点击物料弹出底部抽屉，2×2 单位网格卡片，选中绿底绿边
- **多单位支持**：从 `material_inventory_rule.inventory_units` 读取可选单位，过滤仅 unit 类型（不含称重）
- **换算提示**：每个单位显示 "1箱=24个" 格式的换算关系
- **实时合计**：底部浅绿汇总条显示换算后基准单位总量 + 金额
- **数字键盘**：复用 `DrawerNumericKeyboard` 组件，"确认录入"按钮
- **购物车抽屉**：点击底部 🛒 弹出已选物料列表，每行显示名称+数量+金额+删除✕
- **回填数量**：重新打开已录入物料时自动填入上次数量和单位
- **逐行删除**：购物车 X 只删除该单位行，列表 X 删除整个物料

### 卡片标题简化
- 方向标签（调入申请/调出申请）+ 物料名 + 物流方向
- 标题：`牛油果等3种`，副标题：`调出：南屏街店 → 调入：科技园店`
- 去掉了有歧义的"申请调入/调出"长文本

### 发起调货（form）
- **调出地+调入地**：均从全部门店自由选择，带搜索过滤
- **交接方式**：门店自取 / 第三方物流切换
- **物料选择**：从品项选购页选择，支持多单位
- **自动确认**：调出地=当前门店时，创建后自动确认+发货

### 调货详情（detail）
- **流程记录**：按 `creator_store_id` 判断发起方，进度点按状态变色
- **总金额**：物料列表下方展示 `unitPrice × qty` 汇总
- **底部按钮**：100%宽度，按状态动态显示（取消/确认/收货）

### 门店切换与权限
- **范围卡片**：横向滑动 chips（全部门店 + 名下各门店），单门店仅显示店名
- **全部门店模式**：查看类工具传 `?all=true`，进入各页面展示全门店数据
- **执行类工具**：全部门店时弹出抽屉选门店，单门店直接进入
- **watch(scope)**：切换门店时自动调用 `switchStore` 同步后端 + 重新加载数据
- **发起调货权限**：所有角色均可发起（已移除店员限制）

### 首页重构
- **概览区域**：单门店老板展示经营概览（今日销售+今日支出），多门店展示全部门店概况
- **待处理事项动态化**：盘点（taskRemaining>0）、调货（transferPending>0）、报损（lossPending>0）按条件展示
- **全部门店视图**：待处理事项按门店分组，每张卡片带门店名，点击自动切换到该门店
- **常用工具**：新增支出/上报问题/确认收货/门店报损 四个卡片
- **角色标签**：范围卡片右上角黄色标签（老板/店长/店员）

### 工具页重构
- **删除标题**：Tab 自带标题，页面内不重复
- **工具卡片重构**：彩色渐变背景+右下角图标，统一两列布局
- **权限差异化**：店员隐藏工资工时、人员管理；展示"我的信息"替代
- **品项选购入口**：调货管理 → 发起调货 → 品项选购页

### 新增 API
`fetchTransferList`、`fetchTransferDetail`、`createTransfer`、`confirmTransfer`、`shipTransfer`、`receiveTransfer`、`cancelTransfer`、`rejectTransfer`、`fetchTransferOverview`、`searchTransferMaterials`

### 新增 Store
- `store/transfer.ts` — 调货物料 Pinia Store（多单位支持，单价换算，增删改查）
