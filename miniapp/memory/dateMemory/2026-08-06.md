# 2026-08-06 日常报损多物料改造

## 核心改动
日常报损从「一单一物料」→「一单多物料」。到货验收报损保持单物料不变。

## 数据库
- `V14__loss_report_item.sql`：建 `loss_report_item` 明细表 + 主表 `material_name` 改 nullable + `item_count` + `voucher_url VARCHAR(4000)`
- `V15__migrate_daily_loss_to_items.sql`：存量日常报损迁移到明细表，`item_count` 标记为 1

## 后端

### 新建文件
- `LossReportItem.java` — 明细实体
- `LossReportItemMapper.java` — Mapper
- `DailyLossCreateReq.java` — 请求 DTO（`@Valid List<ItemReq> items`）

### 修改
- `LossReport.java` — 加 `items`/`itemNames`(非DB) + `itemCount`(DB)
- `LossReportService.java` — 加 `createDaily`/`updateDaily`/`deleteDaily`
- `LossReportServiceImpl.java` — `createDaily` 事务创建主+子；`updateDaily` 删旧明细重建；`deleteDaily` 软删除+明细；`getItemsBatch` 批量加载；`enrichMultiItemReports` 列表/详情注入
- `MpLossReportController.java` — `POST /daily`、`PUT /{id}`、`DELETE /{id}`、`POST /{id}/remove-voucher`
- `LossReportManageController.java` — 导出适配多物料（`itemNames`/`共N种`/逐项公式）

## 前端

### form-daily/index.vue（新建）
- 单页滚动布局，支持新增和编辑模式
- 组件：物料搜索底部抽屉 → 编辑抽屉（容器胶囊图片+重量+净重+公式+金额）→ 加入列表
- 列表卡片：名称+规格 | 净重+金额右对齐 | ✕删除
- 报损原因：横向滚动胶囊
- 图片上传：最多 20 张，160rpx 方块网格
- 底部固定栏：报损金额(橙) + 共N种物料 + 确认按钮(绿圆角)
- 编辑模式：`?editId=xxx` 回填，支持增删物料/换容器/改重量/增删图片

### list/index.vue
- 「日常报损」按钮 → `navigateTo form-daily`
- 卡片：`itemNames || materialName`；数量行 `itemCount > 0 ? 'N种物料' : 原逻辑`

### detail/index.vue
- 顶部基础信息卡（类型/原因/登记人/创建/更新）
- 多物料明细清单；去掉计算公式
- 底部固定编辑/删除栏（仅日常报损）
- 编辑 → 跳转 form-daily 回填；删除 → 确认 → 软删除
- `onShow` 刷新；图片仅查看

### pages.json

### api/loss-report.ts

## 设计决策
- `loss_report_item.item_count` 区分新旧：0=扁平，>0=多物料
- 存量单物料编辑时自动迁移到明细表
- 容器：文本胶囊+选中展示图片详情
- 单价显示 4 位小数去尾零
- 编辑跳转表单页而非详情页内编辑（减少页面复杂度）
