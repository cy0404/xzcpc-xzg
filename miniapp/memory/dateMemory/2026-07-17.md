# 2026-07-17 问题处理模块完成

## 概述

问题处理模块（P0 B1）小程序端开发完成，涉及页面、API、组件等。

## 小程序端

### 新增页面

| 页面 | 路径 | 说明 |
|------|------|------|
| 问题列表 | `pages/issue/list/index` | 全部门店切换+概览+状态筛选+问题卡片+已解决/未解决按钮 |
| 问题详情 | `pages/issue/detail/index` | 问题信息+处理记录时间线+方案照片+回复输入+上传+验收确认 |
| WebView 容器 | `pages/webview/index` | 通用 H5 加载页，上报表单用 |
| 视频播放 | `pages/issue/video/index` | 全屏视频播放器+返回按钮 |

### 新增 API

| 模块 | 路径 | 说明 |
|------|------|------|
| `api/issue.ts` | `/issue/list` | 问题列表（支持 all=true 跨门店） |
| `api/issue.ts` | `/issue/overview` | 概览统计 |
| `api/issue.ts` | `/issue/overview-stores` | 按门店待验收计数（首页用） |
| `api/issue.ts` | `/issue/{id}` | 问题详情 |
| `api/issue.ts` | `/issue/by-external/{externalId}` | 按外部ID查问题 |
| `api/issue.ts` | `/issue/{id}/records` | 代理查外部处理记录 |
| `api/issue.ts` | `/issue/{id}/reply` | 代理门店回复 |
| `api/issue.ts` | `/issue/{id}/store-confirm` | 已解决/未解决确认 |
| `api/issue.ts` | `/issue/sync-external` | webview postMessage 同步 |
| `api/issue.ts` | `/issue/upload-media` | 代理上传文件到 task_platform |

### 状态映射

| 外部状态值 | 中文展示 | 标签颜色 |
|-----------|---------|---------|
| PENDING_CONFIRMATION | 待处理 | 灰 |
| IN_PROGRESS | 处理中 | 橙 |
| PENDING_CONTACT | 未联系上 | 红 |
| PENDING_ACCEPTANCE | 待验收 | 橙 |
| CLOSED | 已解决 | 绿 |
| RESOLVED | 已解决 | 绿 |
| OVERDUE | 逾期 | 红 |

### 首页集成
- 单门店：问题待验收计数，描述"X 个待验收"
- 全部门店：按门店分组展示待验收问题
- 常用工具：黄色问题处理入口卡片
- 修复：单门店模式下问题计数取本店而非全部门店汇总（scopeAll 传参）
- 修复：全部门店初始化时加载 issue 待验收数据

### 详情页功能
- 下拉刷新处理记录
- 处理记录+门店回复合并时间线展示
- 回复支持图片/视频附件（点击发送时先上传再回复）
- 待验收状态隐藏回复区，底部显示已解决/未解决按钮
- 已关闭状态隐藏回复区
- 图片点击浮层预览（带X关闭按钮）
- 视频点击独立页播放
