## 三、员工审批修复

### 离职员工重新入职
- 问题1：`jdbcTemplate` 没加 `@Qualifier`，注入成 PG 的 → fix: `PgDataSourceConfig` 加 `@Primary` 的 `mysqlJdbcTemplate`
- 问题2：逻辑删除 `employeeMapper.delete(LambdaQueryWrapper)` 后唯一约束还在，无法 INSERT → fix: 改查旧记录直接 `updateById` + `LambdaUpdateWrapper` 强制置空 `leave_date`
- 问题3：MyBatis-Plus 默认 `NOT_NULL` 策略导致 `setLeaveDate(null)` 不写 SQL → `LambdaUpdateWrapper.set(Employee::getLeaveDate, null)` 强制

```java
// 最终逻辑：冲突时查旧记录更新
Employee old = employeeMapper.selectOne(new LambdaQueryWrapper<Employee>()
    .eq(Employee::getStoreId, application.getStoreId())
    .eq(Employee::getOpenid, application.getOpenid()));
if (old != null) {
    employee.setId(old.getId());
    employee.setDelFlag(0);
    employeeMapper.updateById(employee);
    // 强制置空 leave_date（NOT_NULL 策略会跳过 null）
    employeeMapper.update(null, new LambdaUpdateWrapper<Employee>()
        .set(Employee::getLeaveDate, null).eq(Employee::getId, old.getId()));
}
```
