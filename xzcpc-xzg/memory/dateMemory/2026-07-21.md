# 2026-07-21 后端变更

## 调货还货/还钱模块
- 新表 `transfer_return_record`（`database/migration-transfer-return.sql`）
- `TransferReturnService/Impl` — `doReturn` + `confirmReturn`
- `MpTransferReturnController` — `POST /{id}/return` + `POST /{id}/return-confirm`
- `TransferManageController.detail()` 返回 `returnRecords`
- `MpTransferController.detail()` 返回 `returnRecords` + 填充 item 归还字段
- 归还状态用 `handoff='returned'`（不改 `status`）
- `TransferOrderItem` 新增瞬态字段 `returnedQty`/`returnStatus`/`returnAmount`

### 还货逻辑
- `doReturn`: 还货校验数量上限; 还钱由金额反推 `returnQty = amount / unitPrice`,不设上限
- `getRemainingQty`: 剩余 = transferQty - SUM(goods return_qty) - SUM(money return_amount) ÷ unitPrice
- `confirmReturn`: 仅调出门店,设置 `handoff='returned'`,**移除"物料未完全归还"校验**(调入方确认即算完成,不检查剩余)

### handoff 字段用途变更
- 旧:交接方式(门店自取|第三方物流) → 已废弃
- 新:还货状态 `pending_return`(待还) | `returned`(已还)
- 迁移: `database/migration-handoff-to-return-status.sql`
