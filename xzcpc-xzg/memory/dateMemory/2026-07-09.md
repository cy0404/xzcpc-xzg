# 2026-07-09 后端更新记录

## P0 调货管理模块

### 新增表
- `transfer_order` — 调货单主表（`from_store_id/name`、`to_store_id/name`、`status`、`creator_store_id`、`handoff`、`total_qty`、`created_by`、`confirmed_by`、`shipped_by`、`received_by` 及各时间戳）
- `transfer_order_item` — 调货明细（`material_name`、`spec`、`unit`、`transfer_qty`、`base_unit`、`base_qty`、`input_unit`、`input_qty`、`unit_price`）
- 迁移脚本：`migration-add-transfer-handoff.sql`、`migration-add-base-unit.sql`、`migration-add-creator-store.sql`

### 新增实体
- `TransferOrder` — 含 7 状态流转校验（`assertCanTransition`）
- `TransferOrderItem` — 含两套单位字段（录入单位+基准单位）

### 新增 API（mp 端，`/api/mp/transfer`）
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/` | 发起调货（`fromStoreId`/`toStoreId` 均自由选） |
| PUT | `/{id}/confirm` | 调出方确认 |
| PUT | `/{id}/ship` | 标记发货 |
| PUT | `/{id}/receive` | 调入方确认收货（自动→completed） |

| GET | `/materials/search` | 物料搜索（`unitInfos`+`unitPrices`+多单位筛选） |

### 关键业务逻辑
- **创建即确认**：`fromStoreId == 当前门店` 时自动 `confirmed→pending_ship`（跳过手动确认+发货）
- **creator_store_id**：记录发起门店，用于前端判断"我提的"vs"别人提的"
- **交接方式**：`handoff` 字段（门店自取/第三方物流）
- **物料单位换算**：仅取 `conversion_type='unit'` 的换算规则，称重单位不参与调货
- **单价换算**：BFS 遍历换算链计算各单位相对于 base_unit 的系数
- **两套数量**：`input_unit+qty`（录入值）+ `base_unit+qty`（换算值），同时保存

### 全门店查询支持
- `MpTaskController.list(?all=true)` — 跨名下所有门店查任务
- `MpStaffController.list(?all=true)` — `listAllStoresStaff()`
- `MpTransferController.overview(?all=true)` — `overviewByStores(openid)`
- `MpLossReportController.overview(?all=true)` — 报损按门店统计

### 移除限制
- 调货创建移除店员权限校验（所有角色均可发起）
- 员工列表移除老板过滤（所有门店展示老板信息）
