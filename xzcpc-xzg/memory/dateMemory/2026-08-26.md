## 需求（用户）
每天 9:00 统计未验收问题（`issue.status='pending_acceptance'`），用**黄色预警卡片**发到**每个门店自己的飞书群**（store_info.chat_id），提醒门店在「象子掌柜」微信小程序验收（问题处理 → 待验收 → 点「已解决」）。已确认：卡片发给每个门店自己的群；包含**所有**待验收问题（每天重复提醒直到验收）。

## 排查要点
- **issue 表没有 chat_id 字段**，群 ID 在 store_info（job 按 store_id JOIN 取 s.chat_id）；复现查询：`SELECT i.id,i.store_name,i.status,s.chat_id FROM issue i LEFT JOIN store_info s ON i.store_id=s.store_id AND s.del_flag=0 WHERE i.status='pending_acceptance' AND i.del_flag=0`
- 状态大小写：DB 存 `PENDING_ACCEPTANCE`，SQL 查 `pending_acceptance`——默认 collation 大小写不敏感，能匹配
- **230002 bot not in group**：飞书返回 HTTP 200 + body code != 0，原 sendMessage 不检查响应体 → 静默失败；已加响应体 code 检查记 WARN（FeishuMessageService）
