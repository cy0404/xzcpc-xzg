# 2026-07-08 后端 P0 更新记录

## P0 A2 门店报损模块

### 新增 Controller
- `MpLossReportController` (`/api/mp/loss-report`)：报损 CRUD + 物料搜索 + 容器列表
- `LossReportManageController` (`/api/admin/loss-report`)：总部台账 + 容器管理
- `MpInventoryController` (`/api/mp/inventory`)：扫码识别 + 条码补充

### 新增 Service
- `LossReportService` / `LossReportServiceImpl`：净重计算（半成品去皮）+ 角色权限 + bizCode 生成
- `MpInventoryService` / `MpInventoryServiceImpl`：扫码识别（qm_code/material_id 匹配）

### 新增 Entity / Mapper
- `LossReport`、`LossReportMapper`：loss_report 表
- `ContainerConfig`、`ContainerConfigMapper`：container_config 表
- `BarcodeSupplement`、`BarcodeSupplementMapper`：barcode_supplement 表
- `InventoryDifference`、`DifferenceProcessLog`：盘点差异处理

### 已有文件改动

| 文件 | 改动 |
|------|------|
| `LoginUser.java` | 新增 `role` 字段 + `isStoreManagerOrOwner()` / `isStaffOnly()` |
| `JwtUtil.java` | `generate()` 支持传入 role |
| `MpLoginInterceptor.java` | JWT 提取 role 写入 LoginUser |
| `MpAuthServiceImpl.java` | `determineRole()` 判定老板>店长>员工 |
| `StoreManagerSession.java` | 新增 `role` 列 |
| `MpTaskServiceImpl.java` | 任务 `pending_submit` / `overdue` 状态支持 |
| `TaskServiceImpl.java` | 逾期恢复为进行中 |
| `TemplateZone.java` | 移除 `@TableField("zone_id")` 对齐生产库 |
| `BizCodeUtil.java` | 自增序号改为随机数 |

### 数据库新增表
`loss_report`、`container_config`、`barcode_supplement`、`inventory_difference`、`difference_process_log`、`inventory_template_recommendation`、`transfer_order`、`transfer_order_item`、`logistics_record`、`issue`、`notification_log`
