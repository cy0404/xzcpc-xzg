## 牛油果泥审核卡片改版：3 主tab × 2 子tab（loss-daily-confirm.html）

**需求（用户原话）**：牛油果泥审核卡片分为三个 tab：未审核、已通过、已拒绝，每个 tab 下面都有 已下载、未下载 子 tab。

**用户拍板的 4 个决策**：
- 下载按钮保留（已通过/已拒绝 tab 里可补下载）
- 没有导出按钮（现在只有下载视频 ZIP）
- 无视频（只有图片）的单子算已下载
- 其他类审核页（卡片 B1）不动

**实现（文件在 server/src/main/resources/static/，非 upload/h5，需打包 server）**：
- 归口规则：未审核 = `!r.result`；已通过 = `已登记` 或 `补发`（confirmed_resend/received/not_received 已过审核、走完补发流程，若漏掉会从页面消失）；已拒绝 = `拒绝`
- 子 tab 数量实时统计；每个主 tab 独立记忆子 tab 选择（localStorage `avoSubPending/avoSubPassed/avoSubRejected`），`switchAvoSub()` 同时写 `activeTab`，切主 tab 后刷新仍在原主 tab
- `avoIsDl(r)`：无视频（r.images 里没有 isVideo() 命中的）或 `downloaded=true` → 算已下载
- 删除隐藏的空导出锚点（`exportAvocado` 函数保留但无人调用，后端导出接口未动）
- 顶部统计卡对齐：`statPassed` = 已登记 + 补发（原来是只数已登记）
- 连带修正：原逻辑下「补发」状态的单子在审核页标签错误显示「待审核」，现正确显示「已通过」

## 🐛 Bug 1：点击全选后，再点一次无法取消

**根因**：`onCheckChange()` 全选框回显 = `已勾选数 === 全页 checkbox 总数`，但 `toggleAll(true)` 只勾**当前 tab 可见**卡片（其他 tab、搜索隐藏的卡片不勾）→ 点全选后勾选数 ≠ 总数，全选框**立刻自己弹回未勾选** → 第二次点击被浏览器当成"勾选→全选"，取消分支永远执行不到。

**修复**：`onCheckChange()` 改为按「当前 tab 未被搜索隐藏」的可见集合比较（与 toggleAll 实际控制的集合一致），全选后保持勾选、再点可取消、手动取消部分后全选框自动变未勾选。

## 🐛 Bug 2：审核完卡片留在未审核 tab（改造暴露的遗留）

**根因**：`doMark()` 审核成功后原地更新、不刷新页面——新 tab 结构下刚确认/拒绝的卡片仍显示在「未审核」里，顶部统计也不更新，需手动刷新才归位。

**修复**：`tab==='audit' && materialId` 时 `card.remove()` + 新增 `refreshAvoTabCounts()`（本地 reports 重算三主 tab 的子 tab 数量、`statPending/statPassed/statRejected`、`onCheckChange()` 下载栏状态）。切换主 tab 时页面刷新，卡片在已通过/已拒绝中正确归位。
