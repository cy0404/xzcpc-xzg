# 2026-09-02 门店操作预警卡定稿（文本清单 + 跳转按钮）+ 支出页带参直达

## 背景

WeeklyStoreWarningJob（每周门店操作预警）此前已有雏形（@Scheduled 被注释等待通知）。本会话完成：口径三轮纠正定稿 → 文本分行清单版式（用户拍板）→ 底部「查看支出/报损」双跳转按钮（用户拍板：群卡+个人卡都加，双按钮）→ 9/3 发版验证接口 302 正常。

## 一、预警口径（用户多轮纠正后定稿）

- **触发**：每周一 8:30，cron `0 30 8 ? * MON`（曾调 9:10 → 8:30）
- **统计周期**：上周一 ～ 上周日（`today.minusWeeks(1).with(DayOfWeek.MONDAY)`）
- **数据源**：`expense_record` / `loss_report` 上周 DISTINCT store_id（del_flag=0）；门店全集 = `store_info`（del_flag=0 且 supervisor_name 非空）
- **上榜口径（并集）**：无支出 **或** 无报损 缺任一即上榜；两项统计数分开计（noExpenseTotal/noLossTotal），门店只出现一次、行尾标缺项组合
- ❌ 曾试过的被否方案：仅两项全缺（用户撤回）、表格组件（页面大小/换行问题，最终**用户明确不用表格**）、蓝橙 emoji 块（样式不整洁）、markdown 伪表格

## 二、卡片版式（定稿：文本分行清单）

- 群卡：导语 md（含 `N 位督导 · M 家门店上榜 / 🔵 无支出 X 家 · 🟠 无报损 Y 家`）→ hr → **每督导一个 md 块**（拆块避免单 md 超长，也免 \n\n 拼缝）→ hr → 按钮
- 每督导段：`**督导名**（N家） 🔵无支出x家 · 🟠无报损y家`，随后每店一行 `店名｜无支出、无报损`（missingLabels join `、`，店名兜底空串）
- 个人卡：同一督导段版式 + 同样按钮，只含自己名下门店

## 三、跳转按钮（关键坑：schema 2.0 不支持 action）

- 飞书 **schema 2.0 卡片不支持 `action` 元素**：HTTP 400 `ErrCode 200861 unsupported tag action`（探针实证）
- 带按钮卡改走 **schema 1.0**：`{config:{wide_screen_mode:true}, header, elements:[...]}`（无 schema 字段、elements 顶层），与 LossReportPeriodSummaryJob 同款 → 发送 OK（v1 探针验证）
- 按钮：`{"tag":"action","actions":[{"tag":"button","text":plain_text,"type":"primary|default","url":applink}]}`；URL = `fms.buildApplink()`（`https://applink.feishu.cn/client/web_app/open?appId=..&lk_target_url=encode(serverUrl+path)`）
- **applink 不能带 # 直达 hash 路由**（飞书报「重定向 URL 有误」）→ 按钮先指向同 host 无 # 的 302 中介接口：
  - `GET /api/public/weekly-warning/expense-list-link?startDate&endDate` → 302 `/#/expense?startDate&endDate`
  - `GET /api/public/weekly-warning/loss-list-link?startDate&endDate` → 302 `/#/loss?startDate&endDate`（⚠️ **不传 lossType**=查全部类型；区别于旧 lossListLink 默认 arrival）
  - 中介接口放 LossReportH5Controller（与 trigger-weekly-warning 等手动触发接口同文件）

## 四、支出页带参直达（ExpenseList.vue）

- 仿 LossList：onMounted 读 `route.query.startDate/endDate`（qv 数组兜底）→ `filters.dateRange = [dayjs(s), dayjs(e)]`（isValid 校验）→ 再 fetchRecords
- 需 `import dayjs from 'dayjs'` + `import { useRoute } from 'vue-router'`（原文件只有 `import type { Dayjs }`）
- 报损页 LossList 早已支持带参（不主动清 URL，OAuth 回跳两轮加载兼容）
