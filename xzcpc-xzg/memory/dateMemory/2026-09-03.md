## 二、构建卡点：MpWebMvcConfig 缺 import（真因复盘）

连续两轮 `mvn clean package` 失败，症状先后不同（初看很迷惑）：

1. **第一轮**：task 模块 testCompile 报「程序包 com.xzcpc.task.entity 不存在 / 找不到符号」（DifferenceServiceTest 引用）——看起来像 test 文件/模块配置问题，实际是**下游连锁误报**的入口
2. **第二轮（clean 后）**：错误前移到 mp 模块 compile——`MpWebMvcConfig.java:[49,34] 找不到符号 CacheControl`，**真因浮出**

- 根因：给 /upload/h5/** 加 no-cache 时写了 `.setCacheControl(CacheControl.noCache())` 但**没写 `import org.springframework.http.CacheControl`**（该改动此前从未编译成功打包过，生产 17:37 jar 里没有 no-cache 逻辑）
- 修复：补 import 一行，`clean package -DskipTests -pl server -am` 全量通过
- **经验**：clean 构建遇「自己的包不存在」类诡异报错时，把报错模块的主类编译也列为嫌疑——连锁失败会掩盖真正缺 import 的文件；本轮若早看 reactor 顺序就知道 mp 在 task 之后、task 只是先爆的
