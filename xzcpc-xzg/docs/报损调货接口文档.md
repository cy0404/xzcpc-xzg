# 外部查询接口文档

**模块**：`InventoryReportController`  
**路径前缀**：`/api/reports`  
**鉴权方式**：`Authorization: Bearer {token}`  
**Token 配置**：`report.api.token`（application.yml，默认值 `U09MTyBHZW5lcmF0ZWQgMjAyNg==`）

---

## 1. 到货报损单

```
GET /api/reports/loss-report
```

### 入参

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `months` | String | 否 | 月份，逗号分隔，格式 `YYYY-MM`，如 `2026-07,2026-08`。按 `occurred_date` 筛选 |
| `storeIds` | String | 否 | 门店 ID，逗号分隔 |
| `pageNum` | int | 否 | 页码，默认 `1` |
| `pageSize` | int | 否 | 每页条数，默认 `20` |

### 过滤条件

- `loss_type = 'arrival'`
- `status IN ('registered', 'confirmed_resend', 'received', 'not_received')`

### 返回

```json
{
  "code": 200,
  "data": {
    "records": [
      {
        "bizCode": "LR20260728001",
        "cangkuid": "CK001",
        "xiaochengxuid": "12345",
        "storeName": "测试门店",
        "parentCategory": "水果蔬菜",
        "category": "叶菜类",
        "qmCode": "QM123456",
        "materialName": "大白菜",
        "baseQty": 10.00,
        "baseUnit": "斤",
        "totalAmount": 150.00,
        "status": 1,
        "occurredDate": "2026-07-15",
        "resendStatus": 0,
        "resendDate": ""
      }
    ],
    "total": 100,
    "pageNum": 1,
    "pageSize": 20,
    "pages": 5
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `bizCode` | String | 报损单号 |
| `cangkuid` | String | 门店仓库 ID |
| `xiaochengxuid` | String | 小程序 ID |
| `storeName` | String | 门店名称 |
| `parentCategory` | String | 物料一级分类 |
| `category` | String | 物料二级分类 |
| `qmCode` | String | 物料编码（企迈） |
| `materialName` | String | 物料名称 |
| `baseQty` | BigDecimal | 数量（基础单位） |
| `baseUnit` | String | 单位（基础单位） |
| `totalAmount` | BigDecimal | 总金额 = `input_qty × unit_price` |
| `status` | int | 报损状态，固定 `1`（厂家审批通过） |
| `occurredDate` | String | 报损日期 |
| `resendStatus` | int | 补发状态：`0`=待补发，`1`=已补发 |
| `resendDate` | String | 补发日期（门店确认收货时间），待补发时为空 |

## 2. 日常报损单

```
GET /api/reports/daily-loss
```

### 入参

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `dates` | String | 否 | 日期，逗号分隔，格式 `YYYY-MM-DD`，如 `2026-08-01,2026-08-02`。按 `occurred_date` 精确匹配。优先于 `months` |
| `months` | String | 否 | 月份，逗号分隔，格式 `YYYY-MM`，如 `2026-08`。仅在未传 `dates` 时生效 |
| `storeIds` | String | 否 | 门店 ID，逗号分隔 |
| `pageNum` | int | 否 | 页码，默认 `1` |
| `pageSize` | int | 否 | 每页条数，默认 `20` |

### 过滤条件

- `loss_type = 'daily'`
- `status = 'completed'`

### 返回

```json
{
  "code": 200,
  "data": {
    "records": [
      {
        "bizCode": "LR20260801001",
        "cangkuid": "CK001",
        "xiaochengxuid": "12345",
        "storeName": "测试门店",
        "lossType": "日常报损",
        "parentCategory": "水果蔬菜",
        "category": "叶菜类",
        "qmCode": "QM123456",
        "materialName": "大白菜",
        "inputQty": 10.00,
        "inputUnit": "斤",
        "unitPrice": 0.0200,
        "totalAmount": 0.2000,
        "status": "已录入",
        "reason": "损坏",
        "occurredDate": "2026-08-01",
        "handlerName": "张三",
        "createdAt": "2026-08-01 10:30:00",
        "updatedAt": "2026-08-01 10:30:00"
      }
    ],
    "total": 100,
    "pageNum": 1,
    "pageSize": 20,
    "pages": 5
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `bizCode` | String | 报损单号 |
| `cangkuid` | String | 门店仓库 ID |
| `xiaochengxuid` | String | 小程序 ID |
| `storeName` | String | 门店名称 |
| `lossType` | String | 固定 `"日常报损"` |
| `parentCategory` | String | 物料一级分类 |
| `category` | String | 物料二级分类 |
| `qmCode` | String | 物料编码（企迈） |
| `materialName` | String | 物料名称 |
| `inputQty` | BigDecimal | 数量 |
| `inputUnit` | String | 单位 |
| `unitPrice` | BigDecimal | 单价（4位小数） |
| `totalAmount` | BigDecimal | 总价（4位小数） |
| `status` | String | 状态中文：`已录入` |
| `reason` | String | 报损原因 |
| `occurredDate` | String | 报损日期 |
| `handlerName` | String | 经手人 |
| `createdAt` | String | 创建时间 |
| `updatedAt` | String | 更新时间 |

## 3. 调货单

```
GET /api/reports/transfer-order
```

### 入参

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `months` | String | 否 | 月份，逗号分隔，格式 `YYYY-MM`。按 `completed_at` 筛选 |
| `pageNum` | int | 否 | 页码，默认 `1` |
| `pageSize` | int | 否 | 每页条数，默认 `20` |

### 过滤条件

- `status = 'completed'`

### 拆单规则

每个调货单的每条物料明细拆为 **2 行**：

| 行标识后缀 | transferStatus | 门店 | 说明 |
|-----------|---------------|------|------|
| `_0` | `0` | 调出门店 | 调出方视角 |
| `_1` | `1` | 调入门店 | 调入方视角 |

### 返回

```json
{
  "code": 200,
  "data": {
    "records": [
      {
        "transferItemNo": "TO20260728001_5_0",
        "transferStatus": 0,
        "cangkuid": "CK001",
        "storeName": "调出门店",
        "parentCategory": "水果蔬菜",
        "category": "叶菜类",
        "qmCode": "QM123456",
        "materialName": "大白菜",
        "totalAmount": 200.00,
        "completedAt": "2026-07-20 14:30:00",
        "isReturned": 0,
        "returnDate": ""
      },
      {
        "transferItemNo": "TO20260728001_5_1",
        "transferStatus": 1,
        "cangkuid": "CK002",
        "storeName": "调入门店",
        "parentCategory": "水果蔬菜",
        "category": "叶菜类",
        "qmCode": "QM123456",
        "materialName": "大白菜",
        "totalAmount": 200.00,
        "completedAt": "2026-07-20 14:30:00",
        "isReturned": 1,
        "returnDate": "2026-07-22 10:00:00"
      }
    ],
    "total": 200,
    "pageNum": 1,
    "pageSize": 20,
    "pages": 10
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `transferItemNo` | String | 调货单号 = `{bizCode}_{itemId}_{0或1}` |
| `transferStatus` | int | `0`=调出，`1`=调入 |
| `cangkuid` | String | 门店仓库 ID |
| `storeName` | String | 门店名称（调出/调入方对应） |
| `parentCategory` | String | 物料一级分类 |
| `category` | String | 物料二级分类 |
| `qmCode` | String | 物料编码（企迈） |
| `materialName` | String | 物料名称 |
| `totalAmount` | BigDecimal | 总金额 = `input_qty × unit_price` |
| `completedAt` | String | 调货完成日期 |
| `isReturned` | int | `0`=未还货，`1`=已还货 |
| `returnDate` | String | 还货日期，取最晚归还记录时间，未还货时为空 |

## 鉴权示例

```bash
curl -H "Authorization: Bearer U09MTyBHZW5lcmF0ZWQgMjAyNg==" \
  "http://127.0.0.1:4026/api/reports/loss-report?months=2026-07&pageNum=1&pageSize=20"
```

Token 无效时返回：

```json
{
  "code": 401,
  "msg": "未授权访问",
  "data": null
}
```
