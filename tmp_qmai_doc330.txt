#### 接口的说明/描述

### 请求地址

| 环境 | 请求地址 |
| -------- | -------- |
|沙箱环境|xxx|
|正式环境|https://openapi.qmai.cn/v3/scm/order/transfer/list|

### 公共请求参数
[开发指南->接口调用约定【必读】](https://open.qmai.com/home/documentCenter?id=9)

### 业务请求参数

| 参数 | 描述                      | 是否必须 | 类型 | 示例值 |
| -------- |-------------------------|----|---|------|
|createdEndAt|创建结束时间|false|string|2025-05-22 17:50:20|
|createdStartAt|创建开始时间	|false|string|2025-05-22 17:50:20|
|creator|创建人|false|string||
|inWareNo|调入仓库编码|false|string||
|outWareNo|调出仓库编码	|false|string||
|pageNo|页数,示例值|true|int|1|
|pageSize|每页数量|true|int|10|
|productCodeList|品项编码集合|false|list||
|statusList|单据状态列表：1-待审核 2-待出库 3-已取消 4-已完成 5-已驳回 6-待入库|false|list||
|transferEndAt|调拨结束时间	|false|string|2025-05-22 17:52:58|
|transferStartAt|调拨开始时间	|false|string|2025-05-22 17:52:58|
|transferNoList|调拨申请单号|false|list||
|transferType|调拨类型：1-店间调拨 2-仓店调拨 3-店仓退配 4-仓间调拨|false|int||
|updatedEndAt|修改结束时间		|false|string|2025-05-22 17:52:58|
|updatedStartAt|修改开始时间			|false|string|2025-05-22 17:52:58|
### 请求示例
```javascript
{
    "createdEndAt": "",
    "createdStartAt": "",
    "creator": "",
    "inWareNo": "",
    "outWareNo": "",
    "pageNo": 0,
    "pageSize": 0,
    "productCodeList": [],
    "statusList": [],
    "transferEndAt": "",
    "transferNoList": [],
    "transferStartAt": "",
    "transferType": 0,
    "updatedEndAt": "",
    "updatedStartAt": ""
}
```
