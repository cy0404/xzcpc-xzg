### 消息场景说明

报货单接单消息推送。

### 通用消息格式

| 参数 | 描述 | 是否必须 | 类型 | 示例值 |
| -------- | -------- | ----- | -------- | ------ |
| openId | openId鉴权参数 | true | string | d14c1559e87b747d577c834b275a4310 |
| grantCode | grantCode鉴权参数 | true | string | ba67d4fa46 |
| nonce | 随机正整数 | true | long | 11886 |
| timestamp | 当前时间戳 | true | long | 1465185768 |
| token | token鉴权参数 | true | string | cFw0t9IuvL9jVo9qAzk0qMcw5BM= |
| params | 消息体，详细说明见下方报货单接单消息体说明 | true | jsonString | {} |

### 报货单接单消息体说明

| 参数 | 描述 | 是否必须 | 类型 | 示例值 |
| -------- | -------- | ----- | -------- | ------ |
| sellerId | 店铺id | true | long | 217930 |
| storeId | 门店id | true | long | 555264 |
| declareNo | 报货单号 | true | string | BH20260507000001 |
| amount | 报货金额 | true | decimal | 158400 |
| discountAmount | 优惠金额 | true | decimal | 0 |
| freight | 运费 | true | decimal | 0 |
| orgSubject | 组织主体 | true | string | 加盟门店 |
| joinContract | 加盟合同号 | true | string |  |
| companySubject | 公司主体 | true | string | 重庆公司 |
| remark | 备注信息 | true | string | 报货单接单测试 |
| creator | 创建人 | true | string | system |
| createdAt | 创建时间 | true | string | 1777420800000 |
| storeWarehouseNo | 门店仓库编码 | true | string | MDCK000208 |
| warehouseNo | 仓库编码(配送中心) | true | string | PSCK000021 |
| warehouseMark | 仓库标识(配送中心) | true | string |  |
| channelTradeNo | 支付流水号 | true | string |  |
| accountNo | 收款账户 | true | string |  |
| auditAt | 接单审核时间 | true | string | 1777421100000 |
| onlinePay | 线上支付 0-否 1-是 | true | int | 0 |
| settleSubjectCode | 结算主体 | true | string |  |
| settleSubjectName | 结算主体名称 | true | string |  |
| expArrivalDate | 期望到货日期 | false | date |  |
| productList | 报货单商品明细列表 | true | list | [] |

### 返回示例

回调根据 HTTP 响应码为 `200`，且返回 `{"code":0}` 判断为成功，否则为失败。

返回字符串的 json 格式，内容如下表。

#### 成功格式

```json
{
  "status": true,
  "code": 0,
  "message": "ok"
}
```
