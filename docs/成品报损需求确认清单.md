# 成品报损需求确认清单

> **用途**：需求提出方提出「成品报损」需求，本清单用于向对方逐项确认业务规则。
> **填写方式**：每项给出现状说明 + 待确认问题，对方逐项回复（选项式勾选 + 补充说明）。
> **现状依据**：现有系统已上线「到货验收报损」「日常报损」两套流程（详见文末附注）。

---

## 一、报损对象与范围

**现状**：现有报损分两种——① 到货验收报损（门店收到货验收时发现破损/缺失，厂家飞书确认+补发）；② 日常报损（门店日常损耗，店长审批即完结）。系统已有"成品/半成品"物料属性字段，但未按成品独立跑流程。

**待确认**：
- Q1. 「成品报损」指的是什么场景？
  - □ 门店制作完成的**成品**（如做好的奶茶/餐品）报废
  - □ 门店**成品原料**（已出库但未售出的成品包装商品）报废
  - □ 其他：______
- Q2. 与现有流程的关系？
  - □ 新增独立报损类型（走自己的流程+飞书通知）

  - □ 复用「日常报损」流程，只过滤成品物料

## 附注：现有报损流程参考

**到货验收报损**：小程序提交（企迈单号必填）→ 店长审批 → 厂家飞书审核（确认报损登记/拒绝）→ 确认后补发（其他类）/次月发券（水果蔬菜）→ 门店收货/未收到 → 4 天自动收货。每天 9:30 飞书卡片汇总 + 加急即时红卡。

**日常报损**：小程序多物料提交（≤20 种物料、成品/半成品、半成品自动去皮）→ 店长/老板审批 → 完结（无飞书通知、无补发）。

**飞书卡片配置**：后台可配置各角色收件人（审核人/补发人），按分类区分，每人可配多人。
