## 二、认证方式（必读）

企迈 OpenAPI v3 使用 **HMAC-SHA1 一次性签名**，auth 参数放 JSON body 外层，业务参数嵌套在 `params` 下：

```json
{
  "openId": "71fcea7abc9709d653693116410b5385",
  "grantCode": "WaGI2rqy9b",
  "nonce": 12345,
  "timestamp": 1787000000,
  "token": "签名结果",
  "params": { "...业务参数..." }
}
```

### 签名算法（与项目 QmaiSignUtil.java 一致）

```
1. sortedStr = "grantCode=" + grantCode + "&nonce=" + nonce + "&openId=" + openId + "&timestamp=" + ts
2. encoded = URLEncode(sortedStr)          // 全量编码，含 & 和 =
3. restored = encoded.replace("%3D","=").replace("%26","&")   // 还原 = 和 & 后作为签名原文
4. token = HMAC-SHA1(key=openKey, data=restored)
5. token = Base64(token) 再 URLEncode 后放入 body
```

- `timestamp`：秒级时间戳
- `nonce`：随机正整数（10000~99999）
- 每次调用重新生成，token 一次性有效

### 配置参数

| 参数 | 值 |
|------|-----|
| openId | `71fcea7abc9709d653693116410b5385` |
| grantCode | `WaGI2rqy9b` |
| openKey | `KYDwl5j39Wb71bff5fe6b0434ac6366a913c0dbc947q1SpQyZ` |
| base-url | `https://openapi.qmai.cn` |

## 四、关键语义（实测结论）

### 1. autoOutbound 决定出库方式

| 值 | 行为 | 列表可见性 |
|----|------|-----------|
| 0 | 只创建"**待出库**"单，不扣库存 | ❌ 9.2.6 列表/控制台出库单页都**看不到**，停在待出库队列 |
| 1 | 创建即**立即出库扣库存**，状态直接 = 2 已出库 | ✅ 立即可见 |

- 需要"建单=扣库存"一步到位 → **传 1**
- 只建单走审批/待确认流程 → 传 0（注意：看不到单是正常的，别以为失败）

### 2. price 实测

| 传法 | 结果 |
|------|------|
| 不传 | `code 1021022` 出库单价为空，拒绝创建 |
| 传 0 | ✅ 成功，金额按 0 算 |
| 传具体值 | ✅ 成功，**总价 = num × price** 自动算 |

### 3. 创建响应 data = 出库单号（outboundNo）

```
响应 {"data": 1298672378366070785}  ← 这个值就是 outboundNo
```

实测确认：创建返回的 `data` 与 9.2.6 列表里的 `outboundNo` **完全一致**。所以不需要额外调列表匹配单号，直接用响应 data 即可。

### 4. 幂等

- `bizId`：幂等校验字段，同值重复提交被拦截
- `externalNo`：三方单号需全局唯一（建议：业务单号+序号，如 `SUN20260821001-1`）
- 同业务单分两批出库时，externalNo 必须加序号区分

## 六、注意事项（踩坑记录）

1. **warehouseNo 文档标 false，实际必传一个**（warehouseNo 或 warehouseMark），不传无法确定出库仓库
2. **price 和 productName 实际必传**（文档标 true），price 传 0 可通过，不传报错
3. **pageNo/pageSize 在查询接口 9.2.6 里必须传字符串**（"1" 不是 1），创建接口本身是 int 无碍
4. 控制台/开放 API 的**出库单列表只显示"已出库"（status=2）的单**，待出库单（autoOutbound=0）在控制台"待出库"入口，开放 API 9.2.6 查不到
5. 测试仓库：MDCK000019 = 企迈（总部测试门店）；仓库编码 ≠ 控制台长数字 warehouseId（827599547516627429 那种是控制台内部 ID，开放 API 用编码）

## 七、配套接口

### 9.2.5 出库单物品数量更新

```
POST https://openapi.qmai.cn/v3/scm/order/outbound/order/update
```

参数：outboundNo（必传）、outboundType（必传）、warehouseNo、matchType、productList（同创建）、operator、remark
响应：data（业务id）

### 9.2.6 批量查询出库单

```
POST https://openapi.qmai.cn/v3/scm/order/outbound/order/list
```

| 参数 | 必传 | 类型 | 备注 |
|------|------|------|------|
| createdStartAt | 是 | string | "yyyy-MM-dd HH:mm:ss" |
| createdEndAt | 是 | string | |
| pageNo | 是 | **string** | ★ 传字符串 |
| pageSize | 是 | **string** | 最大 1000，★ 传字符串 |

响应关键字段：outboundNo（出库单号）、outboundType、status（1-待出库 2-已出库 3-已作废）、outboundAt（出库时间）、amount（金额）、outboundProductList（明细：productCode/outboundNum/outboundPrice/outboundAmount/stockUnit）

> ⚠️ 9.2.6 只返回**已出库**的单（实测 500 条全带 outboundAt），待出库单查不到
