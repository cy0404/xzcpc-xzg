# 象掌柜 — 报表接口文档

## 通用说明

- **Base URL**：`http://162.14.122.80:30260/storeInventory/api/reports`
- **认证方式**：HTTP Header `Authorization: Bearer <token>`
- **Token**：`U09MTyBHZW5lcmF0ZWQgMjAyNg==`
- **Content-Type**：`application/json`
- **请求方式**：`GET`
- **错误响应**：`{"code": 401, "message": "未授权访问"}`

> 注：调用总部端内部接口（`/api/reports/*`）时，需在 Header 中传入 `Authorization: Bearer <token>`。内部接口的 token 由 `report.api.token` 配置项统一管理。

## 1. 盘点结果报表

```
GET /api/reports/inventory-result
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| months | string | 否 | 空（查全部） | 盘点月份，多个逗号分隔，如 `2026-05,2026-06` |
| storeIds | string | 否 | 空（查全部） | 门店ID，多个逗号分隔 |
| pageNum | int | 否 | 1 | 页码 |
| pageSize | int | 否 | 20 | 每页条数（按门店数量分页） |

### 请求示例

```bash
curl "http://162.14.122.80:30260/storeInventory/api/reports/inventory-result" \
  -H "Authorization: U09MTyBHZW5lcmF0ZWQgMjAyNg=="

curl "http://162.14.122.80:30260/storeInventory/api/reports/inventory-result?months=2026-05&storeIds=store1,store2&pageNum=1&pageSize=10" \
  -H "Authorization: U09MTyBHZW5lcmF0ZWQgMjAyNg=="
```

### 响应示例

```json
{
  "code": 200,
  "data": {
    "records": [
      {
        "taskMonth": "2026-05",
        "storeId": "cmpaocud700ih3pmbe6opynv0",
        "storeXiaochengxuId": "337330",
        "storeName": "象子茶铺茶新迎新城店",
        "materials": [
          {
            "parentCategory": "原料",
            "category": "茶基底",
            "materialId": "MAT001",
            "materialQmCode": "QM001",
            "materialName": "茉莉绿茶",
            "spec": "500g/袋",
            "inventoryUnit": "袋",
            "unitPrice": 35.00,
            "totalQuantity": 42.00
          }
        ]
      }
    ],
    "total": 100,
    "pageNum": 1,
    "pageSize": 20,
    "pages": 5
  }
}
```

### 字段说明

| 层级 | 字段 | 类型 | 说明 |
|------|------|------|------|
| record | taskMonth | string | 盘点月份，`YYYY-MM` |
| record | storeId | string | 门店ID |
| record | storeXiaochengxuId | string | 门店小程序ID |
| record | storeName | string | 门店名称 |
| record | materials | array | 该门店的物料盘点汇总 |
| material | parentCategory | string | 物料父级分类 |
| material | category | string | 物料子级分类 |
| material | materialId | string | 物料ID |
| material | materialQmCode | string | 物料企迈ID |
| material | materialName | string | 物料名称 |
| material | spec | string | 规格 |
| material | inventoryUnit | string | 盘点单位（取自任务快照，不受后续规则变更影响） |
| material | unitPrice | number | 盘点单价（取自任务快照） |
| material | totalQuantity | number | 物料总量（跨分区汇总） |

```

```

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| months | string | 否 | 空（查全部） | 支出月份，多个逗号分隔 |
| storeIds | string | 否 | 空（查全部） | 门店ID，多个逗号分隔 |
| pageNum | int | 否 | 1 | 页码 |
| pageSize | int | 否 | 20 | 每页条数 |

### 请求示例

```bash
curl "http://162.14.122.80:30260/storeInventory/api/reports/expense" \
```

```json
        ]
      }
    ],
    "total": 50,
```

### 字段说明

| 层级 | 字段 | 类型 | 说明 |
|------|------|------|------|
| record | storeId | string | 门店ID |
| record | storeXiaochengxuId | string | 小程序号 |
| record | storeName | string | 门店名称 |
| record | expenses | array | 该门店的支出记录 |
| expense | expenseId | string | 支出业务编码 |
| expense | expenseMonth | string | 发生月份，`YYYY-MM` |
| expense | firstTypeName | string | 一级分类名称 |
| expense | typeName | string | 支出类型名称 |
| expense | itemName | string | 支出项目名称 |
| expense | amount | number | 金额 |
| expense | occurredDate | string | 发生日期，`YYYY-MM-DD` |
| expense | createdAt | string | 创建时间 |
| expense | delFlag | int | 删除标记：0 正常 / 1 已删除 |

> **注意**：该接口已排除 `first_type_name = '自购成本'` 的记录，自购成本数据请使用下方的独立接口查询。

| months | string | 否 | 空（查全部） | 月份，多个逗号分隔 |
| pageNum | int | 否 | 1 | 页码 |
| pageSize | int | 否 | 20 | 每页条数 |

### 请求示例

```bash
curl "http://162.14.122.80:30260/storeInventory/api/reports/work-hours?months=2026-06&pageNum=1&pageSize=10" \
  -H "Authorization: U09MTyBHZW5lcmF0ZWQgMjAyNg=="

curl "http://162.14.122.80:30260/storeInventory/api/reports/work-hours?storeId=S001&months=2026-05,2026-06" \
  -H "Authorization: U09MTyBHZW5lcmF0ZWQgMjAyNg=="
```

```json
{
  "code": 200,
  "data": {
    "records": [
      {
        "storeId": "S001",
        "storeXiaochengxuId": "wx123",
        "storeName": "XX门店",
        "details": [
          {
            "recordId": "WH20260629001",
            "recordTime": "2026-06",
            "hours": 160.5,
            "createdAt": "2026-06-29 17:00:00",
            "delFlag": 0
          }
        ]
      }
    ],
    "total": 5,
    "pageNum": 1,
    "pageSize": 20,
    "pages": 1
  }

```

### 字段说明

| 层级 | 字段 | 类型 | 说明 |
|------|------|------|------|
| record | storeId | string | 门店ID |
| record | storeXiaochengxuId | string | 小程序号 |
| record | storeName | string | 门店名称 |
| record | details | array | 该门店的工时记录 |
| detail | recordId | string | 工时业务编码 |
| detail | recordTime | string | 月份，`YYYY-MM` |
| detail | hours | number | 工时（小时） |
| detail | createdAt | string | 录入时间 |
| detail | delFlag | int | 删除标记：0 正常 / 1 已删除 |

---

## 通用说明

- 分页按门店维度，`records` 数量 = 不重复门店数
- `delFlag` 不做过滤，调用方自行判断
- 认证失败统一返回 `{"code": 401, "message": "未授权访问"}`
