# 2026-07-21 总部端更新

## 调货台账 TransferList.vue

### 列表新增两列
- **是否完成调货**(key=completed): `status === 'completed'` → 绿/已完成, cancelled/rejected → 灰, 其他 → 橙/进行中
- **是否还货**(key=return): `handoff === 'returned'` → 绿/已还, 其他 → 橙/待还
- 状态筛选去"已归还"选项

### 详情抽屉双 Tab
- **调拨详情**:台账说明+调货信息+物料明细(含单价)+总金额+流程记录
- **还货详情**:每项物料卡片(名称+调拨数+已还+金额)+归还明细列表(类型/数量/金额/经手人/时间)+还清状态标签
- 后端 `TransferManageController.detail()` 返回 `returnRecords`

### handoff 字段用途变更
- 旧:交接方式(门店自取|第三方物流) → 已不用
- 新:还货状态(`pending_return` 待还 | `returned` 已还)
- 迁移:`migration-handoff-to-return-status.sql`
