# 2026-07-27 报损模块重大更新

## 分类差异化处理

报损按 `material_loss_notify_config` 分组，分为水果蔬菜类和其他类两种流程。

### 水果蔬菜类
- 确认报损登记 → registered（已登记）→ 次月3号月度发券 → confirmed_resend → 门店收货
- H5 Tab：待审核 / 已登记

### 其他类
- 确认报损登记 → registered（已登记）→ 厂家"确认发货"→ confirmed_resend → 门店收货
- H5 Tab：待审核 / 待发货 / 已发货

## 新增状态

- `registered`（已登记）：厂家已确认报损登记

## 新增功能

### 加急报损
- 小程序到货验收报损表单新增"是否加急"胶囊
- 仅其他类支持加急
- DB：`loss_report` 表新增 `urgent TINYINT DEFAULT 0`
- 加急提交后 server 端发红色飞书卡片到群

### 月度发券
- 新定时任务：`LossReportMonthlyVoucherJob`（每月3号10:00）
- 新增 H5 页：`loss-monthly-voucher.html`
- 统计上月1号到今天的水果蔬菜类 registered 报损

### H5 确认页改造
- 折叠面板 → Tab 布局
- 拒绝必须填原因
- 搜索框：按物料名/门店名/企迈单号搜索
- 性能优化：批量查配置表替代逐条查库

### 小程序端
- 报损列表改为 6 Tab：全部/待审核/待收货/待确认/已登记/已拒绝
- 拒绝原因红色展示
- 水果蔬菜类 confirmed_resend → "已发券"
- 其他类 registered → "已发券，等待厂家发货"
