#### 接口的说明/描述
接口性能 QPS 10

### 请求地址

| 环境 | 请求地址 |
| -------- | -------- |
|沙箱环境|xxx|
|正式环境|https://openapi.qmai.cn/v3/org/shop/getShopList|

### 公共请求参数
[开发指南->接口调用约定【必读】](https://open.qmai.com/home/documentCenter?id=9)

### 业务请求参数

| 参数 | 描述 | 是否必须  | 类型         | 示例值 |
| -------- | -------- |-------|------------| ------ |
|keyfield|地址/联系电话| false | string     ||
|keyword|门店名称/编码/ID| false | string     ||
|lableId|门店标签id| false | int        ||
|pageNum|当前页数(默认1)| true | int        ||
|pageSize|每页数量(默认10)| true | int        ||
|search|搜索关键字，匹配门店名称、门店详细地址）| false | string     ||
|shopIds|门店ID列表（最多支持传200个门店id，超过200个的建议分多次查询）| false | list ||
|type|机构类型，1=品牌；2=机构；3=门店| false | int        ||
|typeId|机构类型ID| false | long       ||
|containCloseFlag|是否包含停业门店 默认不包含 1-包含| false | int       ||


### 请求示例
```javascript
{
    "keyfield": "",
    "keyword": "",
    "lableId": 0,
    "pageNum": 0,
    "pageSize": 0,
    "search": "",
    "shopChannel": "",
    "shopIds": [],
    "type": 0,
    "typeId": 0,
    "containCloseFlag": 1
}
```
