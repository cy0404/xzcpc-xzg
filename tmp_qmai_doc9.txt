### 请求协议说明
技术服务平台提供的业务API，目前只支持HTTP POST一种请求方式。

<font color="red">
指定Body Content-Type为：application/json

Post请求时，请勿将请求参数放到Query参数中。
</font>

### 接口性能
本平台所有接口，单个接口支持的QPS最高为10，接口文档有特别说明的以具体文档说明为准。<br>
接口的QPS随系统负载升高可能会有波动，为正常现象，请开发者做好重试。

### 参数说明
接口参数分为两部分：公共请求参数和业务请求参数。

#### 公共请求参数
<font color="red">请求所有接口</font>均需要携带的参数，用于开发者身份认证和数据安全校验。公共请求参数包括：

| 参数 | 描述 | 是否必须  | 类型 | 示例值 |
| -------- | -------- | ----- | -------- | ------ |
|openId|openId鉴权参数|true|string|d14c1559e87b747d577c834b275a4310|
|grantCode|grantCode鉴权参数|true|string|ba67d4fa46|
|nonce|随机正整数|true|long|11886|
|timestamp|当前时间戳|true|long|1465185768|
|token|token鉴权参数, 每次请求参数token必须重新生成(注:接口重复请求时,token也要重新生成)|true|string|cFw0t9IuvL9jVo9qAzk0qMcw5BM=|
|params|业务请求参数，格式为jsonString，详细说明见下方【业务请求参数】。该参数为必填参数，如果接口不需要业务请求参数，请传空json对象字符串 "{}"|true|jsonString|{"id":1,"name":"hello"}|

#### 业务请求参数
业务参数是指调用具体某个接口时需要的和业务相关的参数，通常不同的接口有不同的业务请求参数。

<font color="red">业务请求参数统一使用JSON字符串表示</font>，并将此JSON字符串作为指定参数"params"的值。

假如一个接口需要两个参数：id和name，传参的方式可参考：

```javascript
{
    "openId": "d14c1559e87b747d577c834b275a4310",
    "grantCode": "ba67d4fa46",
    "nonce": 11886,
    "timestamp": 1465185768,
    "token": "cFw0t9IuvL9jVo9qAzk0qMcw5BM=",
    "params": {
        "id": 1,
        "name": "hello"
    }
}
```
### 响应格式

所有接口响应Content-Type均为：application/json，即响应均为json格式。接口响应有统一的格式：

#### 成功格式
```javascript
{
    "status": true,
    "code": 0,
    "message": "请求成功",
    "data": {
        "orderNo": "D41171333301684922638"
    },
    "traceId": "bC1010182927573332ea5f6d1da4a56"
}
```

status为true表示请求成功，其他情况都为请求失败。

接口请求成功时data字段表示接口响应的业务数据。

#### 失败格式
```javascript
{
    "status": false,
    "code": 110007,
    "message": "bizId已经存在",
    "data": null,
    "traceId": "bC101018295896049c969c144084c9e"
}
```
traceId为本次调用产生的流水号，接口调用异常，可以提供此流水号用于排查问题。
